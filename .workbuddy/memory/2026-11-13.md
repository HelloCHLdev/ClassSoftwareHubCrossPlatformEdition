# 2026-11-13

## 新增 GitHub Actions 构建/发版流水线

新建两个文件：

- `.github/workflows/build.yml` —— 可复用工作流（`workflow_call` + push/pr/dispatch）。
  矩阵 5 个目标：`windows-2022`(win-x64)、`macos-15`(osx-arm64)、`macos-15-intel`(osx-x64)、
  `ubuntu-24.04-arm`(linux-arm64)、`ubuntu-24.04`(linux-x64)。
- `.github/workflows/release.yml` —— 推 `v*` tag 时复用 build.yml，然后汇总产物发 GitHub Release。

### 关键决策

- **单文件自包含发布**：`PublishSingleFile=true` + `IncludeNativeLibrariesForSelfExtract=true`
  （macOS/Linux 上原生库默认不打包，不加这个 flag 会散成一堆 .so/.dylib）。
- **不裁剪**：`PublishTrimmed=false`。`Services/SettingsStore.cs` / `Pages/SubmitPage.axaml.cs`
  用的是反射式 `JsonSerializer`，裁剪会把 `AppSettings` 这类类型裁掉。
- **macOS 不签名**：.NET 单文件把 bundle 追加在 Mach-O 尾部，`codesign` 会重写签名并挪动文件末尾 →
  把 bundle 偏移写坏。改为在 Release 说明里教用户 `xattr -dr com.apple.quarantine`。
- **产物命名对齐应用内更新器**（`Services/Updating/GitHubReleaseSource.cs`）：
  - 更新器只认 `.exe/.msi/.zip` 后缀，且优先挑名字里含 `setup`/`installer`/`-install` 的资产。
    → Windows 包必须叫 `ClassSoftwareHub-Setup-dv<ver>-win-x64.exe`，macOS zip 不能带 setup 字样。
  - 校验文件必须叫 `checksums.md5`（md5sum 二进制格式 `hash *文件名`），
    `ResolveMd5Async` 会按行匹配资产名再取 32 位 hex。
  - **已知缺口**：更新器的 `PickInstallers` 没有按平台过滤，macOS/Linux 用户会拿到 Windows 的 setup exe。
    要修得改 `GitHubReleaseSource.PickInstallers`（本次没动应用代码）。
- **Debian 版本号**：预发布后缀里的 `-` 要换成 `~`（`1.0.0-beta.1` → `1.0.0~beta.1`），
  否则 `apt install ./xxx.deb` 解析文件名会出错。
- **deb 依赖**：`libicu74 | libicu76 | libicu72 | libicu70` 用 `|` 列多个版本，
  免得在 22.04/24.04/Debian 上装不上；`libstdc++6` 是 SkiaSharp 原生库要的。

### 踩过的坑（重要）

1. **bash 里 `$VAR` 紧跟中文全角括号会被吞进变量名**：写 `$VER）。` 会报
   `VER?: unbound variable`（bash 把全角括号的第一个字节当成了标识符的一部分）。
   → 所有 shell 变量引用统一写成 `${VAR}`。**这个项目代码/注释全是中文，
   以后写任何 bash 片段都要注意。**
2. **YAML block scalar 里的 heredoc 终止符**：终止符必须和命令行**同一缩进**（YAML 会剥掉这段缩进），
   多一个空格就匹配不上，heredoc 会把文件剩余部分全吞掉，而且**退出码还是 0**（静默失败）。
   → heredoc 终止符统一放在 YAML 里与命令相同的缩进。
3. **`ditto -c -k` 默认会用 AppleDouble 把元数据写成 `__MACOSX/._xxx` 条目**，
   要干净就加 `--norsrc`。

### 本地验证方式（很有效，下次照做）

从 YAML 里用 ruby 解析出每个 step 的 `run` 原文，替换掉 `${{ }}` 表达式后**在本地原样执行**，
比肉眼看 YAML 靠谱得多，能抓到上面 2 和 3 这类静默失败。
